# TaskFlow - Task Management Web App

## About
TaskFlow is a practice project focused on building a simple task management application.

## Features
- Task creation
- Task listing
- Task priorities
- Task status tracking
- Bug tracking

## Technologies
- HTML
- CSS
- JavaScript

## Project Management
ClickUp is used to organize development tasks, while Slack is used for project communication.

## Project Status
Initial project setup completed.

## Purpose
This project is created for hands-on practice with GitHub, Slack, and ClickUp.
